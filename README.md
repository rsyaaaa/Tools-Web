**GraphixLab** adalah rangkaian alat bantu grafis (*visual & image tools suite*) modern yang dirancang dengan prinsip **100% Privacy-First**. Seluruh proses pengolahan foto, kompresi, konversi format, hingga pencetakan strip photobooth dilakukan langsung di dalam browser pengguna (Client-Side) tanpa membutuhkan server backend, tanpa API pihak ketiga, dan tanpa pernah mengunggah data atau gambar Anda ke database mana pun.

---

## ⚡ Daftar Fitur Utama

| Fitur | Penjelasan Singkat |
| :--- | :--- |
| **100% Diproses di Browser** | Seluruh operasi grafis dikerjakan langsung oleh mesin browser perangkat Anda (Client-Side). |
| **100% Tanpa Upload Database** | Foto dan data Anda tidak pernah meninggalkan perangkat; zero telemetry & zero data persistence. |
| **Free to Use & Open Source** | Bebas digunakan secara gratis selamanya untuk kebutuhan pribadi maupun komersial. |
| **Bilingual (ID & EN)** | Mendukung penuh peralihan instan antara **Bahasa Indonesia** dan **English**. |
| **Dark Mode & Light Mode** | Tampilan visual elegan dengan tema gelap bertaraf *GitHub Dark* (`#0d1117`) dan mode terang yang bersih. |
| **AI Photobooth (22 Tema)** | Studio foto interaktif dengan live webcam/upload, pilihan 1 hingga 4 shots, ekstraksi palet K-Means, dan 22 tema frame ornamen vektor. |
| **Image Compressor** | Kompresi gambar Lossy & Lossless dengan slider kontrol kualitas instan serta komparasi *side-by-side*. |
| **Image Converter (10 Format)** | Konversi batch berkecepatan tinggi mendukung: **PNG, JPEG, WebP, AVIF, BMP, GIF, ICO, TIFF, SVG,** dan **HEIC/HEIF**. |

## 🛠️ Teknologi yang Digunakan

* **UI Library:** [React 18](https://react.dev/) & [React DOM](https://react.dev/)
* **Build Tool & Dev Server:** [Vite](https://vitejs.dev/)
* **Language:** [TypeScript](https://www.typescriptlang.org/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Icons:** [Lucide React](https://lucide.dev/)
* **Client Decoder:** [heic2any](https://github.com/alexcorvi/heic2any) (Decoder file gambar Apple HEIC di sisi browser)
* **Graphics & Audio Engine:** 
  * HTML5 Canvas 2D API (`CanvasRenderingContext2D`) untuk rendering & compositing foto resolusi tinggi
  * WebRTC Media Stream API untuk live video kamera
  * Web Audio API (`AudioContext`) untuk synthesizer suara shutter prosedural tanpa aset audio eksternal

## 🚀 Cara Instalasi & Menjalankan

Ikuti langkah-langkah mudah di bawah ini untuk menjalankan **GraphixLab** di komputer lokal Anda:

### 1. Prasyarat
Pastikan komputer Anda sudah terpasang:
* [Node.js](https://nodejs.org/) (versi 18.0 atau lebih baru)
* Paket manajer `npm`, `pnpm`, atau `yarn`

### 2. Kloning Repositori
```bash
git clone https://github.com/username/Web-Tools.git
cd Web-Tools
```

### 3. Pasang Dependensi
```bash
npm install
```

### 4. Jalankan Development Server
```bash
npm run dev
```
Setelah server menyala, buka browser Anda dan akses tautan lokal yang ditampilkan (biasanya di `http://localhost:5173`).

### 5. Build untuk Produksi
Untuk mengompilasi aplikasi menjadi file statis siap hosting (*GitHub Pages, Vercel, Netlify, Cloudflare Pages*):
```bash
npm run build
```
File hasil optimasi akan berada di dalam folder `dist/` dan siap dipublikasikan ke server statis mana pun.
